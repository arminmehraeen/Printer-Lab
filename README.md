# PRINTER LAB — شبیه‌ساز پرینت سه‌بعدی

محیط کاری فارسی و راست‌چین برای مشاهده مدل‌های سه‌بعدی، بارگذاری STL و نمایش بصری مسیرهای چاپ با Three.js.

## اجرا روی سیستم شخصی

نیازی به Docker یا Backend نیست. Node.js نسخه 18 یا جدیدتر نصب باشد:

```bash
npm install
npm run dev
```

آدرس محلی Vite (معمولاً `http://localhost:5173`) را باز کنید.

برای ساخت نسخه قابل انتشار:

```bash
npm run build
npm run preview
```

## قابلیت‌های پیاده‌سازی‌شده

- رابط فارسی RTL، طراحی واکنش‌گرا و پوسته تیره
- محیط Three.js با دوربین قابل چرخش، Zoom، Pan، میز چاپ، Grid، محدوده ساخت، نورپردازی و نازل
- بارگذاری فایل STL باینری و ASCII با STLLoader، Drag & Drop و محدودیت حجم ۸۰ مگابایت
- شش مدل نمونه هندسی که به‌صورت محلی و بدون دانلود خارجی ساخته می‌شوند
- محاسبه ابعاد، حجم تقریبی و تعداد مثلث‌ها
- برش هندسه در ارتفاع لایه و تولید قطعات مسیر مقطع؛ نمایش مسیرها و حرکت نازل
- مسیر Infill مستطیلی ساده و قابل تنظیم
- شروع، توقف، ادامه، بازنشانی، تنظیم سرعت و جابه‌جایی در پیشرفت
- پارامترهای قابل تنظیم ارتفاع لایه، قطر نازل، سرعت، تراکم پرشدگی و دما
- تخمین زمان و وزن، همراه با برچسب تخمینی

## معماری

- `src/App.tsx`: محیط کاری، کنترل‌های شبیه‌سازی و اتصال رابط به صحنه
- `src/engine/slicer.ts`: محاسبه برخورد مثلث‌ها با صفحات لایه و تولید مسیرهای بصری
- `src/engine/sampleModels.ts`: هندسه شش مدل نمونه
- `src/styles.css`: طراحی و واکنش‌گرایی رابط
- `src/main.tsx`: نقطه ورود React

## محدودیت‌های فنی مهم

این نسخه یک **شبیه‌ساز بصری و آموزشی** است، نه Slicer صنعتی. مسیرهای مقطع از تقاطع مثلث‌های مش با صفحات افقی ساخته می‌شوند و Infill فعلی یک الگوی مستطیلی ساده در محدوده XY است؛ هنوز contour stitching، perimeter offset، support generation، محاسبه دقیق حجم اکستروژن، جبران قطر نازل، الگوریتم‌های infill واقعی و تولید G-code معتبر دستگاه پیاده‌سازی نشده‌اند. فایل خروجی مسیر نیز صرفاً متن پیش‌نمایش است و نباید به پرینتر واقعی ارسال شود.

مدل‌های نمونه در زمان اجرا از هندسه‌های Three.js ساخته می‌شوند و به فایل‌های STL خارجی وابسته نیستند. فایل STL کاربر به‌صورت محلی در مرورگر پردازش می‌شود و به سرور ارسال نمی‌شود.

## عیب‌یابی

- اگر صفحه خالی بود، ترمینال اجرای Vite و Console مرورگر را بررسی کنید.
- برای مدل‌های سنگین، فایل کوچک‌تر یا تعداد مثلث کمتر انتخاب کنید.
- در صورت مشکل WebGL، شتاب‌دهی سخت‌افزاری مرورگر را فعال کنید.
