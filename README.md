# NEXFORM — شبیه‌ساز پرینت سه‌بعدی

وب‌اپلیکیشن فارسی برای مشاهده مدل‌های سه‌بعدی و شبیه‌سازی بصری مسیر چاپ با Three.js.

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده توسط Vite را در مرورگر باز کنید.

## فناوری‌ها

- React + TypeScript + Vite
- Three.js و STLLoader
- پردازش برش لایه‌ای در مرورگر
- بدون Backend، Docker یا CI/CD

> این برنامه یک شبیه‌ساز آموزشی/بصری است و خروجی مسیر آن جایگزین G-code تأییدشده برای دستگاه واقعی نیست.
